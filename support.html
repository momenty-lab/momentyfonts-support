简体中文

MomentyFonts 支持运行 iOS 或 iPadOS 18 及以上版本的 iPhone 和 iPad。你可以选择 English、中文（简体）、中文（繁体）或日本語，在完整纸张页面上连续书写，并在完成字符集后生成个人 TrueType 字体。

TTF 与可编辑字体包数据

  • .ttf 是 Build 后生成的字体文件。你可以通过系统分享面板保存或发送它；MomentyFonts 不会把它自动安装为 iOS 或 iPadOS 的全局字体。
  • .momentyfont 是可编辑的字体包数据，包含保存的书写内容与设置。它不是可安装字体，也不应作为 TTF 使用。

导出或转移可编辑数据

  1. 在 Font Packs 中打开字体包的 … 菜单，选择 Export Data。
  2. 如果有尚未保存的修改，选择 Save and Export，或取消后继续编辑。
  3. 把 .momentyfont 保存到 Files 或你选择的位置。
  4. 在另一台设备或另一份 App 数据中，如果首次打开显示语言选择，先选择 English 进入 Writing，再点可见的 Packs，然后选择 Import Data。如果已在 Font Packs 页面，直接选择 Import Data。选取该文件后，导入会创建一个新的字体包，不覆盖或自动合并现有字体包。

生成 TTF

打开字体包的 Preview。只有完成所选文字系统要求的字符并保存最新修改后，Build 才会可用。Build 完成后，通过系统分享面板把 .ttf 保存到 Files、AirDrop 或其他目的地。

Momenty Pen

Fixed 0.50 mm 是默认模式。iPad 可以为后续新笔画选择 Pressure；手指输入和整笔没有有效压力数据的输入会保存为 Fixed。iPhone 不显示 Pressure 选项。实际压力效果取决于 iPad 与 Apple Pencil 报告的数据。

提交支持请求

如需支持，请发送邮件至 momenty.lab@gmail.com。请提供 App 版本与 build、iOS/iPadOS 版本、设备型号、发生问题时执行的操作，以及屏幕上显示的完整信息。

请勿发送密码、密钥或不相关的个人数据。如需排查私人笔迹或完整 .momentyfont 文件，请先在邮件中说明问题。

English

MomentyFonts supports iPhone and iPad with iOS or iPadOS 18 or later. Choose English, Chinese (Simplified), Chinese (Traditional), or Japanese, write continuously on complete paper pages, and build a personal TrueType font after finishing the character set.

TTF and editable font-pack data

  • A .ttf file is the font created by Build. You can save or send it through the system Share Sheet. MomentyFonts does not install it automatically as a system-wide iOS or iPadOS font.
  • A .momentyfont file is editable font-pack data containing saved writing and settings. It is not an installable font and should not be used as a TTF.

Export or move editable data

  1. In Font Packs, open a font pack's … menu and choose Export Data.
  2. If the font pack has unsaved changes, choose Save and Export, or cancel and continue editing.
  3. Save the .momentyfont file to Files or another destination you choose.
  4. On another device or in another app data set, if language selection appears on first launch, choose English to enter Writing, tap the visible Packs action, and then choose Import Data. If Font Packs is already open, choose Import Data directly. Select the file. Import creates a new font pack and does not overwrite or automatically merge an existing one.

Build a TTF

Open the font pack's Preview. Build becomes available after you complete the required characters for the selected writing system and save the latest changes. When Build finishes, use the system Share Sheet to save the .ttf file to Files, AirDrop, or another destination.

Momenty Pen

Fixed 0.50 mm is the default. On iPad, you can select Pressure for new strokes. Finger input and an entire stroke without valid pressure data are saved as Fixed. iPhone does not show the Pressure choice. Actual pressure behavior depends on the data reported by the iPad and Apple Pencil.

Request support

For support, email momenty.lab@gmail.com. Include the app version and build, iOS or iPadOS version, device model, the action you were taking, and the complete message shown on screen.

Do not send passwords, keys, or unrelated personal information. If troubleshooting may require private handwriting or a complete .momentyfont file, first describe the issue in your email.
