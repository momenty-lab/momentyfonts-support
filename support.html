简体中文

MomentyFonts 支持运行 iOS 或 iPadOS 18 及以上版本的 iPhone 和 iPad。你可以选择 English、中文（简体）、中文（繁体）或日本語，在完整纸张页面上连续书写，并在完成字符集后生成个人 TrueType 字体。

TTF 与可编辑字体包数据

  • 创建、书写、编辑、保存、App 内 Preview，以及可编辑 .momentyfont 的导入和导出保持免费。
  • 从 1.1 版本起，通过系统分享面板把完成的 .ttf 发送到 MomentyFonts 外，需要一次性“永久 TTF 导出”购买。一次购买可永久解锁所有文字系统的不限次数成品 TTF 导出，不按次收费；价格以 App Store 在当前店面的显示为准。MomentyFonts 不会把字体自动安装为 iOS 或 iPadOS 的全局字体。
  • .momentyfont 是可编辑的字体包数据，包含保存的书写内容与设置。它不是可安装字体，也不应作为 TTF 使用。

导出或转移可编辑数据

  1. 在 Font Packs 中打开字体包的 … 菜单，选择 Export Data。
  2. 如果有尚未保存的修改，选择 Save and Export，或取消后继续编辑。
  3. 把 .momentyfont 保存到 Files 或你选择的位置。
  4. 在另一台设备或另一份 App 数据中，如果首次打开显示语言选择，先选择 English 进入 Writing，再点可见的 Packs，然后选择 Import Data。如果已在 Font Packs 页面，直接选择 Import Data。选取该文件后，导入会创建一个新的字体包，不覆盖或自动合并现有字体包。

生成 TTF

打开字体包的 Preview。只有完成所选文字系统要求的字符并保存最新修改后，Build 才会可用；Preview 本身无需购买。从 1.1 版本起，首次尝试把完成的 TTF 发送到 App 外时，MomentyFonts 会显示“永久 TTF 导出”面板和 App Store 返回的本地化价格。购买或恢复成功后，关闭面板并再次轻点 Build；App 不会自动重放先前的 Build 请求。Build 完成后，通过系统分享面板把 .ttf 保存到 Files、AirDrop 或其他目的地。

购买与恢复

  • 从 1.1 版本起，MomentyFonts 会在启动和回到前台时读取 Apple 验证的当前权益；同一 Apple Account 的永久权益通常会自动识别。
  • 如果权益尚未被识别，请在“永久 TTF 导出”面板中选择 Restore Purchases。购买和恢复使用 Apple App Store 服务，可能需要网络连接或 Apple Account 验证。
  • MomentyFonts 只接受 Apple 验证的权益。无法验证时不会打开待处理的分享面板，但不会删除项目、笔迹、已保存的构建结果、可编辑数据或已保存到 App 外的文件。

Momenty Pen

Fixed 0.50 mm 是默认模式。iPad 可以为后续新笔画选择 Pressure；手指输入和整笔没有有效压力数据的输入会保存为 Fixed。iPhone 不显示 Pressure 选项。实际压力效果取决于 iPad 与 Apple Pencil 报告的数据。

提交支持请求

如需支持，请发送邮件至 momenty.lab@gmail.com。请提供 App 版本与 build、iOS/iPadOS 版本、设备型号、发生问题时执行的操作，以及屏幕上显示的完整信息。

请勿发送密码、密钥或不相关的个人数据。如需排查私人笔迹或完整 .momentyfont 文件，请先在邮件中说明问题。

English

MomentyFonts supports iPhone and iPad with iOS or iPadOS 18 or later. Choose English, Chinese (Simplified), Chinese (Traditional), or Japanese, write continuously on complete paper pages, and build a personal TrueType font after finishing the character set.

TTF and editable font-pack data

  • Creating, writing, editing, saving, in-app Preview, and editable .momentyfont import and export remain free.
  • Starting with version 1.1, sending a finished .ttf outside MomentyFonts through the system Share Sheet requires the one-time Permanent TTF Export purchase. One purchase permanently unlocks unlimited finished-TTF export for every writing system; it is not a per-export charge. The price is the price displayed by the App Store for the current storefront. MomentyFonts does not install the font automatically as a system-wide iOS or iPadOS font.
  • A .momentyfont file is editable font-pack data containing saved writing and settings. It is not an installable font and should not be used as a TTF.

Export or move editable data

  1. In Font Packs, open a font pack's … menu and choose Export Data.
  2. If the font pack has unsaved changes, choose Save and Export, or cancel and continue editing.
  3. Save the .momentyfont file to Files or another destination you choose.
  4. On another device or in another app data set, if language selection appears on first launch, choose English to enter Writing, tap the visible Packs action, and then choose Import Data. If Font Packs is already open, choose Import Data directly. Select the file. Import creates a new font pack and does not overwrite or automatically merge an existing one.

Build a TTF

Open the font pack's Preview. Build becomes available after you complete the required characters for the selected writing system and save the latest changes; Preview itself does not require a purchase. Starting with version 1.1, the first attempt to send a finished TTF outside the app presents the Permanent TTF Export sheet with the localized price returned by the App Store. After a successful purchase or Restore, close the sheet and tap Build again; the app does not replay the earlier Build request automatically. When Build finishes, use the system Share Sheet to save the .ttf file to Files, AirDrop, or another destination.

Purchase and Restore

  • Starting with version 1.1, MomentyFonts reads Apple-verified current entitlement at launch and when returning to the foreground. A permanent entitlement for the same Apple Account is normally recognized automatically.
  • If the entitlement has not been recognized, choose Restore Purchases in the Permanent TTF Export sheet. Purchase and Restore use Apple App Store services and may require a network connection or Apple Account authentication.
  • MomentyFonts accepts only Apple-verified entitlement. If entitlement cannot be verified, a pending Share Sheet is not opened, but projects, handwriting, saved build results, editable data, and files already saved outside the app are not deleted.

Momenty Pen

Fixed 0.50 mm is the default. On iPad, you can select Pressure for new strokes. Finger input and an entire stroke without valid pressure data are saved as Fixed. iPhone does not show the Pressure choice. Actual pressure behavior depends on the data reported by the iPad and Apple Pencil.

Request support

For support, email momenty.lab@gmail.com. Include the app version and build, iOS or iPadOS version, device model, the action you were taking, and the complete message shown on screen.

Do not send passwords, keys, or unrelated personal information. If troubleshooting may require private handwriting or a complete .momentyfont file, first describe the issue in your email.
